# Investment-Behavior-Analysis
An analysis of survey-based financial investment behavior and preferences using Microsoft Excel and Power BI.

## Project Overview
This project explores survey-based financial investment behavior and preferences using Microsoft Excel and Power BI.

The analysis focuses on understanding how individuals choose investment avenues, what influences their financial decisions, and how investment preferences vary across different demographic groups.

## Objectives
- Analyze survey-based financial investment patterns.
- Understand investment preferences across genders.
- Explore popular saving objectives.
- Examine the relationship between saving objectives and investment avenues.
- Present insights through interactive Power BI dashboards.

## Tools & Technologies
- Microsoft Excel – Dataset handling and preparation.
- Microsoft Power BI – Data visualization, dashboard creation and analysis.

## Dashboards

### 1. Survey-Based Financial Investment Insights
- Average investor age
- Investment type distribution
- Saving objectives
- Gender distribution
- Investment purposes

### 2. Gender-Based Investment Preferences
- Gender-wise investment preferences
- Mutual fund and government bond preferences
- Investment expectations

### 3. Impact of Savings Objectives on Investment Decisions
- Saving objectives and investment avenues
- Investment preferences across saving objectives
- Comparison of gold, bonds, mutual funds, equity and fixed deposits
